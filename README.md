# Portfólio — Guilherme Gonçalves Pereira

Site estático responsivo em HTML, CSS e JavaScript, preparado para publicação no GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: identidade visual, layout responsivo e estilos.
- `script.js`: menu mobile e ano automático no rodapé.

## Antes de publicar
1. Abra `index.html`.
2. Na seção **Contato**, substitua `SEU-EMAIL@EXEMPLO.COM` pelo e-mail profissional que deseja tornar público.
3. Substitua os links genéricos do LinkedIn e GitHub pelos seus perfis reais.
4. Revise o conteúdo e confirme que pode divulgar os detalhes dos projetos.
5. Não publique telefone, endereço residencial, documentos ou dados de clientes.

## Publicar no GitHub Pages
1. Crie uma conta em https://github.com/ (se ainda não tiver).
2. Crie um repositório público chamado `portfolio`.
3. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
7. Aguarde a publicação. O endereço aparecerá na própria página de configurações do Pages.

## Observações de conteúdo
O texto foi estruturado a partir das informações do currículo fornecido. Os projetos são apresentados como descrições; não foram inventados links, imagens de evidência ou repositórios. Acrescente provas reais (prints sem dados confidenciais, README dos projetos e código que possa compartilhar) quando disponíveis.
